## Getting Started

### Prerequisites

Install the following tools before running the programs:

- [Visual Studio Code](https://code.visualstudio.com/)
- [GCC/G++ Compiler](https://www.mingw-w64.org/) or another compatible C/C++ compiler

### Clone the Repository

Open your terminal and run:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the repository folder:

```bash
cd YOUR_REPOSITORY_NAME
```

Replace the placeholders with your actual GitHub repository URL and repository name.

### Compile and Run a C Program

Compile a C source file:

```bash
gcc program.c -o program.exe
```

Run it in Windows PowerShell:

```powershell
.\program.exe
```

### Compile and Run a C++ Program

Compile a C++ source file:

```bash
g++ program.cpp -o program.exe
```

Run it in Windows PowerShell:

```powershell
.\program.exe
```

Replace `program.c` or `program.cpp` with the name of the source file you want to run.
